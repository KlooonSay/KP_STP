# AGENTS.md

## Назначение проекта

`Склад Native` — нативное приложение macOS для ведения перечня товаров с хранением данных в SQLite, контролем срока реализации и формированием печатных отчётов.

## Архитектура

- `Sources/Store.swift` — модель `Product`, валидация, работа с SQLite, импорт и экспорт данных.
- `Sources/Interface.swift` — интерфейс SwiftUI, формы, навигация и пользовательские действия.
- `Sources/Report.swift` — формирование табличного отчёта средствами AppKit и системная печать.
- `Resources/schema.sql` — схема исходной базы.
- `Tests/CoreChecks.swift` — автоматические проверки основной логики.
- `build.command` — проверка и локальная сборка `.app` на macOS.

## Ограничения среды

Графическая часть зависит от SwiftUI и AppKit, поэтому требует macOS 13+ и не собирается в стандартном Linux-контейнере Docker.
