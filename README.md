# Склад Native

Нативное приложение для macOS, предназначенное для ведения перечня товаров на складе. Программа написана на Swift с использованием SwiftUI и AppKit, данные хранятся в SQLite.

## Возможности

- просмотр перечня товаров;
- поиск по наименованию, виду и шифру;
- добавление, изменение и удаление записей;
- автоматическое определение просроченных товаров;
- формирование отчётов по всем товарам и по просроченным позициям;
- расчёт стоимости товарных позиций;
- системная печать и сохранение отчёта в PDF;
- экспорт и импорт данных в формате `.sklad`;
- резервное копирование и транзакционная замена данных при импорте.

## Технологии

- Swift;
- SwiftUI;
- AppKit;
- SQLite;
- macOS 13+.

## Структура проекта

```text
SkladNative/
├── Sources/
│   ├── Store.swift       # модель данных, SQLite, валидация, импорт/экспорт
│   ├── Interface.swift   # пользовательский интерфейс SwiftUI
│   └── Report.swift      # построение и печать отчётов
├── Resources/
│   ├── warehouse.db      # исходная база данных
│   ├── schema.sql        # схема SQLite
│   └── AppIcon.icns      # иконка приложения
├── Tests/
│   └── CoreChecks.swift  # проверки основных операций
└── build.command         # локальная сборка приложения
```

## Сборка и запуск на macOS

Для сборки требуются Apple Command Line Tools и SDK macOS 13 или новее.

1. Распакуйте проект.
2. Запустите `build.command`.
3. Скрипт выполнит проверки основных операций и соберёт приложение.
4. Готовый файл `Склад Native.app` появится в каталоге `dist`.

При отсутствии Command Line Tools выполните:

```bash
xcode-select --install
```

Рабочая база пользователя хранится отдельно от приложения:

```text
~/Library/Application Support/SkladNative/warehouse.db
```

Поэтому повторная сборка или замена `.app` не удаляет ранее сохранённые данные.

## Проверки

Перед сборкой графического приложения `build.command` компилирует и запускает набор проверок из `Tests/CoreChecks.swift`. Проверяются основные операции SQLite, уникальность шифра, вычисление стоимости, работа с датами, импорт/экспорт и откат транзакции при ошибке.

## Docker

Графическая версия приложения использует SwiftUI и AppKit — системные фреймворки macOS. Docker Desktop на macOS запускает Linux-контейнеры, в которых отсутствуют macOS SDK, SwiftUI и AppKit. По этой причине нативное `.app` не может быть собрано и запущено внутри стандартного Linux-контейнера Docker.

В репозитории присутствует `Dockerfile`, который воспроизводимо создаёт контейнер со Swift toolchain, помещает внутрь исходный код проекта и демонстрирует ограничение контейнерной среды. Само графическое приложение собирается и запускается непосредственно в macOS с помощью `build.command`.
